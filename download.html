2. 공식 MAME2. Official MAME

세이부 컵 사커의 공식 MAME 지원은 지원 예정입니다. 지원되는 버전이 나오면 mamedev.org의 64비트 Windows 버전을 그대로 쓸 수 있게 됩니다. 그때까지는 1번 패키지에 든 mame.exe를 쓰면 됩니다.Official MAME support for Seibu Cup Soccer is coming soon. Once a supporting version is out, the 64-bit Windows build from mamedev.org will simply work. Until then, the mame.exe inside package 1 is all you need.

공식 MAMEOfficial MAME

패키지의 MAME와 라이선스The MAME in the package and its license
공식 MAME는 아직 이 게임의 보호칩(SEI300 / COP3)을 제대로 흉내 내지 못해 경기가 진행되지 않습니다. 그래서 패키지에는 이것을 고친 비공식 수정판 MAME(bin\mame.exe, MAME 0.289 + 패치 키트로 빌드)가 들어 있습니다. MAME 팀의 공식 배포판이 아니며 MAME 팀과 관계가 없습니다. 고친 내용은 rmonic79 님이 실제 기판으로 검증한 MiSTer 코어의 COP3 분석을 MAME 0.289로 옮긴 것입니다. Official MAME still cannot emulate this game's protection chip (SEI300 / COP3), so matches do not run. The package therefore carries an unofficial, fixed build of MAME (bin\mame.exe, MAME 0.289 built with the patch kit). It is not an official MAME release and is not affiliated with the MAME team. The fixes port rmonic79's hardware-verified COP3 analysis from the MiSTer core to MAME 0.289.
패치는 GNU GPL v3입니다(MiSTer 코어의 라이선스를 따릅니다). 그래서 패키지의 mame.exe도 GPL v3(또는 이후 버전)로 배포하며, 라이선스 전문은 패키지의 bin\legal\, 안내는 bin\MAME_README.txt에 있습니다. 소스: MAME 0.289 (mame0289 태그) + 패치 키트. mame.exe를 따로 나눠 줄 때는 이 안내와 소스도 함께 주세요. 게임 롬(cupsoc.zip)은 패키지에도, mame.exe와도 함께 배포하면 안 됩니다. 롬은 각자 합법적으로 소유한 것만 쓰세요. The patch is GNU GPL v3 (following the MiSTer core's license), so the package's mame.exe is distributed under the GPL v3 or later; the license texts are in the package's bin\legal\ and the notes in bin\MAME_README.txt. Source: MAME 0.289 (tag mame0289) + the patch kit. If you pass mame.exe on by itself, include those notes and the source. The game ROM (cupsoc.zip) must never be bundled with the package or with mame.exe; use only a copy you legally own.

시작하기Getting started

  1. 다운로드 페이지에서 넷플레이 패키지를 받아 원하는 폴더(예: C:\seibucup)에 풉니다. 이 게임용 MAME(bin\mame.exe)까지 들어 있습니다. Program Files 같은 보호된 폴더만 피하세요.Get the netplay package from the Download page and unzip it anywhere (e.g. C:\seibucup). It already contains the MAME for this game (bin\mame.exe). Just avoid protected folders such as Program Files.
  2. 본인이 소유한 cupsoc.zip 롬을 패키지의 mame\roms\ 폴더에 넣습니다. 셀렉션 버전도 하려면 cupsocs2.zip도 함께 넣습니다. (롬은 제공하지 않습니다.)Put your own cupsoc.zip ROM into the package's mame\roms\ folder, and cupsocs2.zip too if you want the Selection edition. (We do not provide ROMs.)
  3. 처음이라면 런처의 튜토리얼 버튼으로 조작부터 익히세요(접속 없이 혼자, 레슨 11개). 조이스틱이나 다른 키는 튜토리얼 안에서 Tab → Input Settings → Input Assignments (this system) → P1 항목에서 바꾸며, 넷플레이에도 그대로 쓰입니다.New to the game? The launcher's Tutorial button teaches the controls (offline, on your own, 11 lessons). Set a joystick or other keys inside it under Tab → Input Settings → Input Assignments (this system) → P1; netplay uses them too.
  4. SeibuCupNetplay.exe를 열고 닉네임을 입력한 뒤 "접속". 상대를 찾는 가장 빠른 길은 빠른 대결(단판)입니다 - 기다리는 사람이 있으면 바로 붙고, 없으면 CPU와 게임하며 기다리다 누가 들어오면 시작합니다. 친구와 하려면 방을 고르거나 만들고, 모두 준비를 누르면 5초 카운트다운 뒤 MAME가 자동으로 뜹니다.Open SeibuCupNetplay.exe, enter a nickname, press Connect. The quickest way to find an opponent is Quick match (single): it joins somebody who is waiting, or lets you play the CPU until somebody joins you. To play with a friend, pick or create a room instead; when everybody has pressed Ready, MAME opens by itself after a 5-second countdown.
  5. 경기 시간이 끝나면 결과가 기록되고 게임 창이 몇 초 뒤 저절로 닫히며, 방에 그대로 남아 다음 경기를 할 수 있습니다. 도중에 그만두려면 창을 닫으세요(X 버튼 또는 Alt+F4, 게임 중 ESC는 막혀 있음) - 그러면 방에서 나갑니다. 자세한 내용은 플레이 방법.At full time the result is recorded and the game window closes by itself a few seconds later; you stay in the room for the next match. To stop in the middle, close the window (X button or Alt+F4; ESC is locked during play) - that takes you out of the room. More in How to play.

버전에 대하여 게임은 두 가지 버전으로 나왔고(기본, 셀렉션) 런처에서 고를 수 있습니다. 보통 받는 cupsoc.zip에는 기본 버전만 들어 있습니다. 셀렉션까지 하시려면 cupsocs2.zip을 같은 폴더에 넣거나, 클론이 모두 든 병합(merged) cupsoc.zip을 쓰시면 됩니다. 없는 버전은 런처가 알려 주고 막아 주니, 잘못 골라도 대전이 깨지지 않습니다.
About versions The game came in two versions (the original and Selection) and the launcher lets you pick. An ordinary cupsoc.zip contains only the original. For Selection, add cupsocs2.zip to the same folder, or use a merged cupsoc.zip that holds every clone. A version you do not have is refused with an explanation, so a wrong pick cannot spoil a match.
