mamedev.org

MAME 직접 빌드 (COP3 패치) - 정식 MAME 지원 전까지 제공합니다Build your own MAME (COP3 patch) - offered until official MAME support arrives

공식 MAME는 아직 이 게임의 보호칩(SEI300 / COP3)을 제대로 흉내 내지 못해 경기가 진행되지 않습니다. 정식 지원 전까지는 아래 패치 키트로 각자 자기 PC에서 고쳐진 MAME를 만들어 쓰세요. 실행 파일은 제공하지 않고, 필요한 도구(컴파일러, MAME 소스)를 키트가 스스로 내려받아 빌드한 뒤 스스로 지웁니다. 더블클릭 한 번, 5~40분, 여유 공간 6 GB.Official MAME still cannot emulate this game's protection chip (SEI300 / COP3), so matches do not run. Until it is supported, use the kit below to build a fixed MAME on your own PC. No executable is distributed: the kit downloads the tools (compiler, MAME source) by itself, builds, and cleans up after itself. One double-click, 5-40 minutes, 6 GB of free space.

패치 키트Patch kit

압축을 풀어 setup_mame.cmd를 실행하면 끝입니다. 넷플레이 패키지 폴더 안에 풀면 bin\mame.exe가 바로 제자리에 놓입니다. Windows 10/11 64비트, 공백·한글이 없는 경로(예: C:\seibucup). 관리자 권한은 필요 없습니다(시스템에 아무것도 설치하지 않음). 단, Program Files 같은 보호된 폴더에는 두지 마세요. 파란 "PC 보호" 경고가 뜨면 추가 정보 → 실행.Unzip and run setup_mame.cmd. Unzipped inside the netplay package folder, it puts bin\mame.exe straight in place. Windows 10/11 64-bit, a path without spaces or non-English characters (e.g. C:\seibucup). No administrator rights needed (nothing is installed system-wide); just keep it out of protected folders such as Program Files. If the blue "protected your PC" box appears: More info → Run anyway.

실행 스크립트, 패치 적용 스크립트(MAME 0.289의 seibucop 파일 4개를 고침), 라이선스 전문, 크레딧, 설명서. 고친 내용은 rmonic79 님이 실제 기판으로 검증한 MiSTer 코어의 COP3 분석을 MAME로 옮긴 것입니다.The run script, the patch script (fixes four seibucop files of MAME 0.289), the full license text, credits and a readme. The fixes port rmonic79's hardware-verified COP3 analysis from the MiSTer core to MAME.

시작하기Getting started

  1. 다운로드 페이지에서 런처를 받고, 공식 MAME를 설치합니다.Get the launcher from the Download page and install official MAME.
  2. 본인이 소유한 cupsoc.zip 롬을 MAME의 roms 폴더에 넣습니다. (롬은 제공하지 않습니다.)Put your own cupsoc.zip ROM into MAME's roms folder. (We do not provide ROMs.)
  3. 런처를 열고 닉네임을 입력한 뒤 "접속". 방을 고르거나 만들고, 친구가 들어오면 "게임 시작".Open the launcher, enter a nickname, press Connect. Pick or create a room; when your friends are in, press Start game.
