후원Support

서버를 계속 돌리는 데 힘이 됩니다. 고맙습니다.It keeps the server running. Thank you.

CPS2가 기억나네요. 슈퍼 스트리트 파이터 2가 에뮬레이팅되던 그 감동이 최근에 다시 느껴져서 얼른 만들었습니다.I still remember CPS2. The thrill of seeing Super Street Fighter II emulated for the first time came back to me recently, so I built this as fast as I could.

아직 구동 가능한 MAME 정식판은 나오지 않았지만, 그 전에 빌드할 수 있도록 도움을 준 rmonic79 님께 감사드립니다.An official MAME release that runs the game is not out yet, and I am grateful to rmonic79, whose work made it possible to build one before that.

아시겠지만 이 게임은 2:2가 '진리'입니다. 그래서 네트워크로 함께 즐길 수 있는 프로그램을 만들어 배포합니다.As you probably know, this game is meant to be played 2 vs 2. So here is a program that lets you play it together over the network.

후원은 서버 운영비와 더 좋은 프로그램을 만드는 데 쓰입니다.Donations cover the server costs and go toward making the program better.
