어떻게 동작하나요?How does it work?

정품 MAME 그대로Stock MAME

공식 MAME에 작은 넷플레이 스크립트만 얹습니다. 에뮬레이션은 건드리지 않아 화질·속도·조작감이 평소와 같습니다.A small netplay script runs inside official MAME. Nothing about the emulation changes - same picture, speed and feel.

락스텝 넷플레이Lockstep netplay

양쪽 PC가 같은 프레임에 같은 입력을 적용합니다. 어긋나면 자동으로 다시 맞춥니다. 화면 우측 상단에 핑이 표시됩니다.Every PC applies the same inputs on the same frame; if they ever drift, they resync automatically. Your ping is shown on screen.

방 만들고 들어가기Rooms

런처에서 닉네임만 넣고 접속. 방 목록에서 고르거나 새 방을 만듭니다. 1 vs 1, 2 vs 2, 핑 제한, 비밀번호 방.Enter a nickname and connect. Pick a room or create one: 1 vs 1, 2 vs 2, ping limits, private rooms.

2 vs 2 자동 팀 구성2 vs 2 made easy

코인·스타트·팀 합류를 런처가 자동으로 처리합니다. 1P와 3P는 나라를 고르기만 하면 됩니다.Coins, starts and team joins are automatic; players 1 and 3 just pick their countries.

내 조작 설정 그대로Your own controls

MAME에 설정한 P1 키·조이스틱을 몇 번째 플레이어든 그대로 씁니다. 코인 5, 스타트 1 - 모두 똑같이.Your P1 keys or joystick work whichever seat you get. Coin 5, start 1 - the same for everyone.

4개 언어 · 다크 모드4 languages · dark mode

한국어 · English · 日本語 · 中文, 라이트/다크/시스템 테마.Korean · English · Japanese · Chinese, light / dark / system themes.

시작하기Getting started

  1. 다운로드 페이지에서 넷플레이 패키지(런처)를 받아 원하는 폴더에 풉니다. 폴더 이름에 한글이나 공백이 있어도 됩니다.Get the netplay package (launcher) from the Download page and unzip it anywhere. Non-English characters or spaces in the folder name are fine.
  2. 패키지의 bin\ 폴더에 mame.exe를 넣습니다. 정식 MAME이 이 게임을 지원하기 전까지는 다운로드 페이지의 "MAME 직접 빌드" 키트로 직접 만듭니다.Put mame.exe into the package's bin\ folder. Until official MAME supports this game, build it yourself with the "Build your own MAME" kit on the Download page.
  3. 본인이 소유한 cupsoc.zip 롬을 패키지의 mame\roms\ 폴더에 넣습니다. (롬은 제공하지 않습니다.)Put your own cupsoc.zip ROM into the package's mame\roms\ folder. (We do not provide ROMs.)
  4. (선택) play.cmd로 게임을 한 번 혼자 실행해 Tab → Input (this machine) → P1 항목에 조이스틱이나 원하는 키를 설정합니다. 넷플레이에서도 그 설정을 씁니다.(Optional) Run the game alone once with play.cmd and set your joystick or keys under Tab → Input (this machine) → P1. Netplay uses the same settings.
  5. SeibuCupNetplay.exe를 열고 닉네임을 입력한 뒤 "접속". 방을 고르거나 만들고, 방 채팅으로 인사한 뒤 친구가 다 들어오면 방장이 "게임 시작". 5초 카운트다운 뒤 MAME가 자동으로 뜹니다.Open SeibuCupNetplay.exe, enter a nickname, press Connect. Pick or create a room, say hello in the room chat, and once everybody is in the host presses Start game. MAME opens by itself after a 5-second countdown.
  6. 경기가 끝나면 MAME 창을 직접 닫습니다(X 버튼 또는 Alt+F4). 게임 중에는 ESC가 막혀 있습니다. 창을 닫으면 런처가 로비로 돌아옵니다. 자세한 내용은 플레이 방법.When the match is over, close the MAME window yourself (X button or Alt+F4); ESC is locked during play. The launcher returns to the lobby. More in How to play.
